# CSV-наборы для демо импорта заявок в Перми

Наборы подготовлены для локального проекта №1 и его текущего справочника типов работ:

- `Устанвока интернета` — название взято из текущей БД без исправления опечатки;
- `Проводка провода`.

Если тестируется другой проект, значения в колонке `Тип заявки ВК` нужно заменить на точные названия его активных типов работ.

## Наборы

- `perm_success_semicolon.csv` — основной демо-файл: 10 корректных заявок, `;`, UTF-8, дополнительная игнорируемая колонка.
- `perm_success_comma.csv` — 4 корректные заявки, `,`, адреса с запятыми заключены в кавычки.
- `perm_duplicate_seed.csv` — сначала загрузить и применить одну заявку.
- `perm_duplicate_check.csv` — после предыдущего шага должен дать `POSSIBLE_EXISTING_DUPLICATE`; файл отличается по контрольной сумме за счёт дополнительной колонки.
- `perm_parser_errors.csv` — детерминированные ошибки полей, дат, окна, типа работ и дубли внутри файла.
- `perm_nominatim_edge_cases.csv` — реальные пермские адреса, для которых текущий Nominatim возвращает несколько OSM-объектов одного дома; текущий backend помечает их как `ADDRESS_AMBIGUOUS`.

## Порядок демо

1. Загрузить `perm_success_semicolon.csv`, дождаться окончания проверки и применить.
2. Загрузить `perm_success_comma.csv`, чтобы показать работу другого разделителя и CSV-кавычек.
3. Для демо предупреждения последовательно применить `perm_duplicate_seed.csv`, затем загрузить `perm_duplicate_check.csv` и подтвердить предупреждение.
4. Отдельно показать экран ошибок на `perm_parser_errors.csv` и реальную проблему Nominatim на `perm_nominatim_edge_cases.csv`.

## Важно о Nominatim

Адреса из успешных наборов проверены 20.09.2026 на текущем локальном snapshot Nominatim теми же параметрами, что и backend: `countrycodes=ru`, `bounded=1`, `viewbox=50.5,62.0,60.5,55.5`, `limit=10`, `addressdetails=1`. Каждый из них вернул ровно один российский результат с городом, улицей, номером дома и координатами.

Snapshot OSM/Nominatim может измениться после переимпорта данных. Необычно высокая доля `ADDRESS_AMBIGUOUS` здесь не случайна: backend отклоняет адрес, если Nominatim возвратил больше одного OSM-объекта, даже если это контур дома и точка организации по тому же адресу.
